# Loop Launcher

An endless, looping app shelf for Android. Free, open source, no ads, no data collection.

- **Every feature is free and stays free.** An optional one-time **Loop Pro** (Google Play, no subscription)
  unlocks a few extras on top: gesture actions, the flip clock and the idea box. It never locks anything that is free.
- Donations keep the project going. Supporters can ask to appear on the in-app supporter board
  ([supporters.json](supporters.json), names added by hand, only on request).
