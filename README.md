# Loop Launcher

A light, fast Android home screen: a card deck, smart folders, drag and drop, seven code-drawn wallpapers
and Loopi, a tiny robot in the corner. Free, no ads, no data collection.

**What's new in 1.3:** Off / Light / Full effects with a performance test that recommends one, six new free
wallpapers (Aurora, Wild West, Night city, Grid, Cosmos, Sakura), hold the clock to move or resize it,
lock the home screen layout, an optional fingerprint before uninstalling, an app suggestion when headphones
or a car connect, tablet scaling and a new app icon.

- **Every feature is free and stays free.** An optional one-time **Loop Pro** (Google Play) unlocks a few extras
  on top: Loopi's looks, voices and moves, folders in the dock, App pulse, gesture actions, extra clock styles
  and the idea box. It never locks anything that is free.
- Donations keep the project going. Supporters can ask to appear on the in-app supporter board
  ([supporters.json](supporters.json), names added by hand, only on request).
